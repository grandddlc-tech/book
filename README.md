# Lumen Reader

A mobile-first English reading practice app (B2 / C1).

- Short stories: War & History, Romance, Horror (each with its own colour mood)
- Non-fiction articles: science, medicine, biology, history, psychology, technology, environment, space, economics, language, art, philosophy
- A brand-new 600–900 word text is generated by Claude every time you pick a topic
- Tap any word: Persian meaning, American IPA and pronunciation, an example sentence, and "Save to Word Book"
- Word Book with search and flash-card review
- Reading timer with words-per-minute
- 4 IELTS/IMAT-style multiple-choice questions with answers and explanations
- Progress page: texts read, accuracy, saved words, reading speed

## Files

- `src/page.html`: the app (published as a Claude artifact, where text generation runs on the viewer's Claude account and data is saved privately per user)
- `index.html`: standalone build (`./build.sh`). Opened outside Claude, it asks for an Anthropic API key, kept in the browser's localStorage, and saves data locally.
